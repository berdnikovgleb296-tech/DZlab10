# Домашнее задание к работе 10: Меню выбора
## Условие задачи
Составить программу, которая для заданной фигуры (равнобедренный треугольник) предлагает меню выбора одной из операций:
1. рассчитать площадь;
2. вывести определение фигуры;
3. нарисовать фигуру. Реализовать соответствующие функции.

# 1. Алгоритм и блок-схема
Алгоритм
1. Начало
2. Ввод данных:
  Вывести меню на экран.
Запросить у пользователя номер операции (choice).
Выбор действия (switch-case):
case 1: Запросить основание (a) и высоту (h). Вызвать функцию area_triangle(a, h) и вывести результат.
case 2: Вызвать функцию print_definition().
case 3: Запросить высоту (h). Вызвать функцию draw_triangle((int)h).
default: Вывести сообщение об ошибке.
